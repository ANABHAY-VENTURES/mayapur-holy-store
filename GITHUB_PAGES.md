# Deploy Mayapur Holy Store with GitHub Pages

## Recommended repository
Create a GitHub repository named:

`mayapur-holy-store`

The site is configured for:

`https://d-majumder.github.io/mayapur-holy-store/`

## Upload
Upload the contents of this folder to the repository root. Keep these folders intact:

- `assets/`
- `videos/`

and these files:

- `index.html`
- `styles.css`
- `script.js`
- `favicon.svg`
- `site.webmanifest`
- `robots.txt`
- `sitemap.xml`

## Enable GitHub Pages
Repository → Settings → Pages

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`
- Save

GitHub Pages will publish the site at the URL above.

## SEO / social sharing
The site includes:
- title + meta description
- canonical URL
- Open Graph title/description/image
- Twitter/X large-card metadata
- Schema.org Store structured data
- robots.txt
- sitemap.xml
- favicon + web manifest
- semantic headings and descriptive image alt text

### Important
After the site is live, paste the public URL into Facebook Sharing Debugger, LinkedIn Post Inspector and similar link-preview tools to refresh cached previews.
